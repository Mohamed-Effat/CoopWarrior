## What's new

**A live Dashboard.** The Dashboard now draws your keyboard next to the controller it drives. Each key you bound
sits where it is on a real keyboard, lights up while you hold it, and a line underneath names what it does,
for example "Move up + Move right". Below that, the Dashboard shows every other controller Windows sees,
each with its player number, so you can check who is Player 1 before you start a game.

**Stays out of the way.** Minimizing or closing the window now keeps Co-op Warrior running next to the clock,
and your keyboard controller keeps working. Click the icon to open the window again; right-click it to turn
the keyboard controller on or off, or to exit. If you prefer the old behavior, turn it off on the new
**Settings** page.

**A new logo.** One controller, two players: a keyboard half and a controller half.

## Good to know

- To quit Co-op Warrior, right-click its icon next to the clock and choose **Exit**. F12 still turns the
  keyboard controller off.
- The icon may sit under the small arrow next to the clock. Drag it onto the taskbar to keep it in sight.

## Install

Download **CoopWarrior-win-Setup.exe** below and run it. If you already have Co-op Warrior, it updates
itself; your profiles and settings are kept.
